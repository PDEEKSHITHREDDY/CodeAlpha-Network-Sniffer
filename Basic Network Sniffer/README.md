# 🛡️ Secure Code Auditor (Python)

A modern cybersecurity tool for **static code analysis** that detects vulnerabilities in Python source code using automated scanning techniques.

---

## 🚀 Overview

Secure Code Auditor is a professional-grade static analysis tool designed to identify security vulnerabilities in Python applications. It provides detailed reports, severity classification, and remediation suggestions through a modern dashboard interface.

This project simulates real-world cybersecurity tools used in **SOC environments, DevSecOps pipelines, and application security auditing**.

---

## 🎯 Features

### 🔐 Security Analysis
- Detects hardcoded credentials
- Identifies command injection vulnerabilities
- Flags unsafe subprocess usage
- Detects weak cryptographic practices
- Identifies insecure deserialization
- Detects dangerous imports and execution risks

### 📊 Dashboard & UI
- Modern dark cybersecurity-themed UI
- Real-time scan results
- Vulnerability statistics
- Severity distribution visualization
- Interactive components and animations

### 📂 File Scanning
- Upload Python files for scanning
- Multi-file support (extendable)
- Real-time scan processing
- JSON-based report generation

### 📑 Reporting System
- Detailed vulnerability reports
- Severity levels (Low, Medium, High)
- File-wise issue breakdown
- Export-ready data (JSON)
